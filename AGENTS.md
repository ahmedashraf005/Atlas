# Repository workflow

This project is connected to https://github.com/ahmedashraf005/Atlas.

The user wants completed code changes committed and pushed to this repository.
After making requested changes, run the relevant checks, review the diff for
secrets and unintended files, commit the changes, and push the working branch
to its upstream on `origin`, unless the user instructs otherwise. Set the upstream
when pushing a new branch. Do not force-push or commit unrelated user changes.
If authentication or a push fails, explain what the user needs to do.
